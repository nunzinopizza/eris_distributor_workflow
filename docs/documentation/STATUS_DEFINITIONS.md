# Documentation Status Definitions

| Status | Meaning |
|---|---|
| Task to Complete | The document exists as a controlled placeholder, but its substantive design work has not yet been completed. |
| Draft | Verified source material has been entered, but the document is incomplete and is not yet authoritative. |
| Needs Refinement | The document is substantially populated, but one or more conflicts, ambiguities, deferred decisions, or presentation issues must be resolved. |
| Finalized | The document has been reviewed, contains no known unresolved requirements within its stated scope, and may be treated as authoritative until formally revised. |

A document may not be marked Finalized merely because it is useful for beginning development. Deferred decisions, internal conflicts, or unverified implementation details must remain visible.
